# 🚗 Car Rental System

A simple **Java-based Car Rental System** designed to manage car rental operations through a structured application.

This project is organized as a Java module, with the main source files located in the `src` directory.

---

## 📌 Project Overview

The **Car Rental System** is a Java project intended to handle basic car rental operations. The project follows a standard Java project structure and can be opened and developed using an IDE such as **IntelliJ IDEA**.

## ▶️ How to Run the Project

### Using IntelliJ IDEA

1. Clone or download this repository.
2. Open **IntelliJ IDEA**.
3. Select **Open**.
4. Choose the `Car Rental System` project folder.
5. Make sure a valid **JDK** is configured.
6. Locate the main Java file inside the `src` folder.
7. Run the application.

### Using the Command Line

Compile the Java source file:

```bash
javac Main.java
```

Then run the program:

```bash
java Main
```

> Replace `Main.java` and `Main` with the actual name of the main class if your project uses a different class name.
